# Repository Cleanup Audit

Date: 2026-07-29

## Scope and method

This audit reviewed the repository-wide tracked file list, ignored and untracked
files, file types and sizes, exact duplicate hashes, Git history, exact path
references, generic screenshot/snapshot references, runtime asset loads, Python
path constants, tests, documentation, manifests, ignore rules, and current Git
status. The cleanup deliberately preserves source and curated data, public export
artifacts, institution and mapping evidence, review decisions, audit evidence,
migration records, and publishing safeguards.

## Generated locally and ignored

Existing rules already ignore Python bytecode, pytest caches, logs, raw OpenAlex
API downloads, selected processed OpenAlex intermediates, local geocoding
outputs, and the exploratory candidate map export.

This cleanup added the following root-scoped rules:

```gitignore
/visual-regression-*.png
/local_diff_before_*.patch
/local_staged_diff_before_*.patch
/local_status_before_*.txt
```

The visual rule prevents the historical manual screenshot naming convention
from being committed again without ignoring any future canonical baseline stored
under a maintained test fixture or snapshot directory. The backup rules cover
only the reviewed root-level emergency-backup conventions.

## Validation

Post-cleanup validation results:

- `python3 -m pytest -q`: 699 passed, 20 skipped, and two failed. Both
  failures are the same pre-existing repository-baseline mismatch: the committed
  public map contains 1,080 relationships while
  `tests/baseline_expectations.py` expects 1,077. No baseline or metadata was
  changed because doing so would be outside this cleanup and could weaken an
  authoritative guard.
- `python3 scripts/validate_curated_database.py`: passed with zero errors,
  155 existing review warnings, and zero duplicate candidates.
- `python3 scripts/validate_public_preview.py`: passed; existing author mapping
  coverage warnings remain.
- `python3 -m compileall -q scripts tests` with bytecode redirected outside the
  repository: passed.
- Bundled Node.js `--check` over all eight `web/*.js` files: passed.
- `python3 scripts/run_pipeline.py --dry-run`: passed and resolved all six
  normal candidate-pipeline commands without writing files.
- `python3 scripts/export_public_preview.py --dry-run`: correctly reached and
  enforced the shrinkage guard, then exited nonzero because a fresh export from
  the current local candidate inputs would remove 88 papers and 236 map
  relationships without durable evidence. This is an existing data/publishing
  condition unrelated to cleanup; the guard was not bypassed or weakened.
- Public static preview via `python3 -m http.server`: `/`, `/web/`, all local
  HTML/CSS/JavaScript/logo assets, public and sample JSON, and linked local
  documentation returned HTTP 200.
- Admin preview via `scripts/serve_admin.py`: `/admin/`, Admin CSS/JavaScript,
  shared labels, and the linked mapping report returned HTTP 200; `/admin`
  returned its expected HTTP 307 redirect.
- `git diff --check`: passed.

The real `admin_publish_changes.py` command was not completed because it would
commit and push. A probing `--help` invocation revealed that this script has no
argument parser and begins the actual refresh; it was interrupted before commit
or push, and the single generated audit file it touched was restored exactly to
the clean pre-audit Git state.
